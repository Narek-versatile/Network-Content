# PART 3: ANALYTICAL / THINKING TASKS

## 1. Your school network is slow. List 3 possible reasons related to:

### Devices

- NIC is overwhelmed
- CPU is not able to process the incoming packets
- The hardware is not good enough to load the contents

### Network type

- LAN is not configured properly
- MAN headquarters are limiting the bandwidth
- WAN provider is limiting the speed of your connection

### Media (cables/Wi-Fi)

- Wireless over a long distance could cause connectivity issues
- Wired network might have physical weak spots
- Satellite network is widely accessible, but with very limiting conditions

## 2. When would you choose:

**Fiber over Ethernet?**

**Ethernet over Wi-Fi?**

When the host will need constant heavy-load work to do with network, usually servers

## 9. Why is IPv6 important for the future?

IPv4 has very tight limitations in quantity terms also mentioning the growing need for more public IP addresses. IPv6 is the next generation protocol that will support humanity for many years ahead
