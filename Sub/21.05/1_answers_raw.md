Part 1: Basic Concepts

1. What is a domain?

domain is an address for a website. you can buy a domain name and assign it an IP address. example: google.com

2. What is hosting?

hosting is the process of putting a service on a server, usually accessible from the internet. it can be a website, an application, or any other service.

3. What is a VPS?

Virtual Private Server or VPS is a physical server's part that is separated from other parts of the server by virtualization software, and is assigned a private IP address and a private storage. You then use a connection method(e.g. ssh) for connecting and configuring your VPS.

4. What is a VPC (Virtual Private Cloud)?

VPC or Virtual Private Cloud is a isolated network environment inside a larger public cloud. it allows you to create your own private network, subnets, routing tables, etc. and deploy your resources inside it.

5. What is a server?

A server is a computer that provides data, services, or resources to other computers, known as clients, over a network.

6. What is a public IP address?

a public IP address is a an ip address that is accessible from internet. For example, if you want to access your website from another computer on the internet, you need to use a public IP address.

7. What is a private IP address?

a private IP address is the IP address your device gets when connecting to LAN. It is not accessible from the internet. It is used for communication within the LAN. 

8. What is DNS?

DNS or Domain Name System is a system that translates domain names to IP addresses. 

9. What is SSH?

SSH or Secure Shell is a cryptographic network protocol for operating network services securely over an unsecured network. The most common use of SSH is for remote login and command-line execution.

10. What is Nginx?

Nginx or engine-x is a free and open-source web server. It can also be used as a reverse proxy, load balancer, mail proxy, and HTTP cache.

11. What is the purpose of DNS?

DNS is used for associating domains with IP numbers and if there were no DNS we would need to remember all IPs we needed.

12. What is the difference between a domain and hosting?

domain name is like the address of your house, while hosting is the house itself. you need both to have a website.

13. What is the difference between a VPS and shared hosting?

The main difference between VPS and shared hosting is the amount of resources allocated to each user. shared hosting is like living in an apartment building where you share resources with other tenants, while VPS is like having your own house with dedicated resources.

14. What is the difference between a public IP and a private IP?

Public IP address is accessible from the internet, while private IP address is not accessible from the internet. 

15. Why do servers need IP addresses?

Servers need IP addresses for communicating with the clients and proxies and potentially with other servers. Without IP addresses computers would not know where to send data and where to receive data from.
